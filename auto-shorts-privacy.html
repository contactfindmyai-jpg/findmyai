auto-shorts: Privacy Policy

Last updated: November 20, 2026

auto-shorts is a personal, non-commercial tool operated by Kélyan Edmond (contact: edmondkelyan@gmail.com). It runs only on the operator's own computer and is used only by the operator to publish short vertical videos (YouTube Shorts) to the operator's own YouTube channel.

Use of YouTube API Services

auto-shorts uses YouTube API Services. By using auto-shorts, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data processed by Google.

Information accessed

auto-shorts requests a single permission, the OAuth scope https://www.googleapis.com/auth/youtube.upload. It uses it only to upload videos, with their title, description and tags, to the authorized channel.

It does not read, collect or analyze any other data from YouTube or Google accounts: no viewer data, no comments, no analytics and no personal information about other users.

Information stored

The OAuth access and refresh tokens are stored locally on the operator's computer, in a file that never leaves that computer. Videos and their metadata are stored locally until they are uploaded, then deleted. auto-shorts has no server, no database and no analytics.

Information shared

auto-shorts does not share, sell or transfer any data to third parties. Data is sent only to YouTube, to perform the uploads requested by the operator.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings. Deleting the local token file removes all stored authorization data immediately. Any locally stored data is deleted within 30 days of a revocation request.
